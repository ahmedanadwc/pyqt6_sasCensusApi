Files to copy
1. streamlit_app.py (repo root). This is the real app, and it puts src/ on sys.path relative to itself.
2. src/py_sascensusapi/: __init__.py, config.py, sas_backend.py, census_catalog.py, cli.py
3. src/py_sascensusapi/streamlit_app.py, a 15-line shim that cli.py launches. It reads the root streamlit_app.py from three directories up.
4. pyproject.toml, uv.lock and .python-version (3.13), so uv sync can rebuild the environment.

Not needed: tests/, graft/, graphify-out/, .claude/, docs/, check_cache.py, run_ast.py, and the backup file streamlit_app_bkup.py. The tracked src/py_sascensusapi/layouts/*.json files are leftover Marimo layouts and nothing uses them.

Outside the repo (must exist at the new location)
- SAS project repo (sasCensusApiLocalGitRepo): it holds code/macros/{censusapi,etl,util}, data/ and output/. config.py finds it in this order:
  a. the SAS_PROJECT_ROOT environment variable
  b. the current directory
  c. the parent directory
  d. a sibling sasCensusApiLocalGitRepo
  e. ~/sasCensusApiLocalGitRepo
  f. a hardcoded /home/anawarehousing/... fallback

  Easiest: set SAS_PROJECT_ROOT explicitly. It must be the path as the S
- SASPy config (sascfg_personal.py): set SAS_CFGFILE, or put it in ~ or ~/.config/saspy/. config.py checks those three places.
- Cache directory ~/.cache/py_sascensusapi/: it is created automatically and is optional.

Two things could bite you:
- Installed package: if you pip install the package, the shim won't find the root streamlit_app.py because the wheel doesn't include it. Deploy the folder layout above, or the CLI will show a blank page.
- Hardcoded fallback: the /home/anawarehousing/... fallback in config.py is machine-specific. That is why SAS_PROJECT_ROOT should be set.

Next: run uv sync in the new directory, then uv run streamlit run streamlit_app.py.
